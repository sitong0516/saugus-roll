# Saugus Roll

A five-page semantic HTML and CSS class project: a fictional modern roller-skating rink in Saugus, Massachusetts.

## Structure

- `index.html` — Homepage: welcome, site purpose, overview of all five pages
- `about.html` — About the rink concept and the creator, image credits
- `quotes.html` — Five famous quotes grouped by theme, with sources
- `funfacts.html` — Five roller-skating history facts in an ordered list, with sources
- `map.html` — Saugus location description with an embedded Google Map
- `css/styles.css` — One shared external stylesheet for all five pages
- `images/` — Original SVG illustrations created for this project

## Notes

- Open `index.html` in a browser to preview. Google Fonts and the embedded map need an internet connection.

1. Validate all five HTML files at https://validator.w3.org/nu/ and save screenshots.
2. Validate `css/styles.css` at https://jigsaw.w3.org/css-validator/ and save a screenshot.
3. Publish to GitHub Pages (upload the files above to the repository root).
4. Submit the site URL, repository URL, and validation screenshots on Canvas.
